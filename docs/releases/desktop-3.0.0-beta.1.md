# MMPlayer 3.0.0-beta.1 para Windows

Primera beta de MMPlayer para Windows x64. Esta versión está en pruebas: agradecemos
los informes de errores con los pasos para reproducirlos.

**Esta beta se distribuye sin firma digital pública.** Windows puede mostrar un
aviso de editor desconocido o SmartScreen. El archivo `SHA256SUMS.txt` permite
comprobar que la descarga coincide con el instalador publicado. La firma pública
está prevista para una versión posterior.

- Biblioteca local, playlists, etiquetas, estadísticas y varias colas de reproducción.
- Reproductor persistente, letras y visualizaciones de carátula, CD, vinilo, casete y Canvas.
- Controles multimedia de Windows e integración opcional con Discord Rich Presence.
- Copias de seguridad JSON/ZIP, importación de música ZIP y archivos de letras LRC.
- Instalador por usuario, sin necesidad de administrador. La biblioteca y los ajustes
  se conservan al reinstalar y desinstalar.

Descarga el instalador de Windows x64 adjunto a esta publicación. No requiere Node,
Electron ni otras herramientas de desarrollo instaladas.

Limitaciones de esta beta:

- LocalCast/Chromecast y las funciones Supporter/VIP no forman parte de esta versión.
- «Abrir con MMPlayer» desde el Explorador está previsto para una versión posterior.
- Las búsquedas de letras y carátulas dependen de servicios externos.
- Las actualizaciones se instalan descargando el nuevo instalador; esta beta no se
  actualiza automáticamente.

Antes de probar la beta, recomendamos crear una copia de seguridad de la biblioteca,
especialmente si vas a editar metadatos de tus archivos musicales.
